# Change: Operator console (React)

## Why
A minimal but real operator surface to demonstrate escalation, takeover, and hand back, plus
a reviewable rendering of artifacts and evidence.

## What changes
React (JavaScript) + Vite app at `apps/operator-console`: Runs page, Live Session page with
viewport + control bar + context panel + event log, Interventions inbox, Artifact viewer.

## Out of scope
Auth, multi-operator, mobile layout. The CLI demo does not require the console.
